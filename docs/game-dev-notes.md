# 游戏开发学习记录

## 当前认知

会 Java 和 Go 不等于会游戏开发。

Java 和 Go 更适合：

- 游戏后端。
- 账号系统。
- 背包系统。
- 任务系统。
- 活动系统。
- 排行榜。
- 日志和数据分析。

## 需要逐步补的能力

- Unity 或 Godot：理解客户端和玩法原型。
- Blender：理解模型、材质、灯光、资源导出。
- 板绘：理解角色、UI、图标、视觉表达。
- 管线开发：理解资源如何从制作工具进入引擎。
- 编辑器开发：理解配置工具、关卡工具、资源检查工具。
