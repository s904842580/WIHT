# 云原生学习记录

## 当前结论

当前阶段不做 Docker 和 k8s。

原因：

- 你的电脑可能无法稳定运行 Docker。
- 现在首要目标是用 IDEA 跑通 Spring Boot 项目。
- 云原生是后续升级能力，不是第一阶段阻塞项。

## 后续学习顺序

1. Linux 基础命令。
2. Nginx 基础代理。
3. Docker 镜像、容器、端口、数据卷。
4. Docker Compose。
5. 服务健康检查。
6. Prometheus 和 Grafana。
7. k3s/Kubernetes。
