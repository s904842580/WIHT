# 2026-07-11 开发记录

## 今天完成

- 将统一响应改为 `BaseResponse<T>`，统一业务异常改为 `ServiceException`。
- 增加 `@LoginUser` 参数注入，减少 Controller 对 Servlet API 的直接依赖。
- JWT 校验后再次读取数据库用户状态，禁用或删除用户不能继续使用旧 token。
- 完成个人笔记的新建、编辑、删除、发布和撤回发布接口。
- 通过 `created_by` 限制普通用户只能管理自己的笔记。
- 增加 React 受保护路由、我的笔记页面和 Markdown 双栏编辑器。
- 使用 `react-markdown` 与 `remark-gfm` 统一编辑预览和公开正文渲染。
- 增加演示笔记 UTF-8 修复迁移脚本。

## 关键决策

- 公开阅读继续使用 `/api/notes`，只返回 `PUBLISHED` 数据。
- 作者操作统一放在 `/api/my/notes`，避免公开接口和写入权限互相干扰。
- 新建笔记始终先进入 `DRAFT`，发布使用独立动作，减少误公开风险。
- 当前保持 Spring Boot 单体和分层包结构，不提前拆微服务。
