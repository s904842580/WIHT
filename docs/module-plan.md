# 模块规划

## 当前优先级

当前阶段先完成 Java 后端、React 前端和数据库的核心内容闭环。

优先级：

1. 项目基础设施：统一响应、异常、日志、健康检查。
2. 用户基础模块：用户表、注册、登录。
3. 学习笔记模块：文章、分类、标签。
4. 项目展示模块：项目、技术栈、链接、封面。
5. 素材管理模块：素材元数据，不直接管理版权素材。
6. 游戏科普模块：游戏系统文章和案例。

## 暂不实现模块

以下模块只保留规划：

- Go 排行榜服务。
- AI 学习助手。
- 算法可视化前端。
- 独立管理后台（当前已有集成在 `waht-web` 的个人写作台）。
- Docker/k8s 部署。

## 第一阶段业务边界

当前基础要求：

- 能在 IDEA 中启动后端。
- 能连接本地 MySQL。
- 有清晰的表设计。
- 登录注册、公开查询和作者写作接口可联调。
- 代码注释完整。

暂不要求：

- 高并发。
- 微服务。
- 容器化。
- 云原生部署。
