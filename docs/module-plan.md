# 模块规划

## 当前优先级

第一阶段只做 Java 后端和数据库设计。

优先级：

1. 项目基础设施：统一响应、异常、日志、健康检查。
2. 用户基础模块：用户表、注册、登录。
3. 学习笔记模块：文章、分类、标签。
4. 项目展示模块：项目、技术栈、链接、封面。
5. 素材管理模块：素材元数据，不直接管理版权素材。
6. 游戏科普模块：游戏系统文章和案例。

## 暂不实现模块

以下模块只保留规划：

- Go 排行榜服务。
- AI 学习助手。
- 算法可视化前端。
- 管理后台。
- Docker/k8s 部署。

## 第一阶段业务边界

第一阶段只要求：

- 能在 IDEA 中启动后端。
- 能连接本地 MySQL。
- 有清晰的表设计。
- 有基础接口。
- 代码注释完整。

不要求：

- 漂亮前端。
- 高并发。
- 微服务。
- 容器化。
- 云原生部署。

## 建议模块顺序

### Step 1：基础工程

- Maven 配置。
- Spring Boot 启动类。
- 统一响应。
- 全局异常。
- 健康检查。

### Step 2：数据库设计

- 用户表。
- 笔记表。
- 项目表。
- 素材元数据表。

### Step 3：学习笔记模块

- 新增笔记。
- 查询笔记：公开列表和详情已完成。
- 分类查询：公开查询已完成。
- 标签查询：公开查询已完成。

### Step 4：项目展示模块

- 项目列表：公开查询已完成。
- 项目详情：公开查询已完成。
- 技术栈字段：公开查询已完成。
- 项目链接字段：公开查询已完成。

### Step 5：素材元数据模块

- 素材名称。
- 素材分类。
- 素材来源。
- 是否可公开。

素材文件本体不一定由后端管理，第一阶段只记录元数据。
