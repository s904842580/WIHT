# 开发路线

## Day 1：目录和规则

- 确定目录存放规则。
- 明确哪些目录当前使用，哪些目录后续再做。
- 统一 Markdown 文档编码为 UTF-8。
- 确定素材使用边界。
- 明确后端结构由 WAHT 自己维护，不强制参考其他项目。

## Day 2：Spring Boot 3 后端骨架

- 建立 `backend/waht-java`。
- 生成 Maven 基础结构。
- 保证 Maven 仓库使用 `G:\maven\repository`。
- 只做启动类、统一响应、异常处理、健康检查。

## Day 3：数据库基础

- 建立 `database/mysql/init`。
- 设计用户表、笔记表、项目表、素材元数据表。
- 暂不追求复杂权限。
- SQL 先写清楚注释。

## Day 4：第一个业务模块

建议先做学习笔记模块。

原因：

- 最贴合个人平台。
- 对前端展示有直接价值。
- 难度适中。

## 当前已提前完成

- Java 后端登录。
- Java 后端注册。
- JWT 鉴权。
- React 前台基础工程。
- 前台登录页和注册页。
- 学习笔记公开查询接口。
- 前台学习笔记列表和详情页。
- 项目展示公开查询接口。
- 前台项目列表和详情页。
- 统一 `BaseResponse` 与 `ServiceException` 基础层。
- JWT 用户状态二次校验和受保护前端路由。
- 我的笔记列表、新建和编辑页面。
- 草稿、发布、撤回和删除闭环。
- Markdown/GFM 正文渲染与实时预览。
- Markdown 工具栏、快捷键、全屏编辑、内容统计和本地草稿恢复。

- 前端全局错误边界与严格端口配置。
