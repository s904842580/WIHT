# 前端本地视觉素材

这个目录存放页面运行时需要的前端图片。每个素材必须记录来源和公开状态。

## 当前文件

### plum-spirit-login.jpg

- 用途：登录与注册页背景。
- 来源：项目生成素材。
- 状态：本地使用，公开前需要再次审核。

### odette-current.avif

- 用途：首页“现在正在欣赏”轮播的奥黛塔画面。
- 来源：用户在 2026-08-23 提供的《原神》相关图片。
- 状态：仅用于本地、非商业的个人交流预览。
- Git：已加入 `.gitignore`，不能提交到公开仓库。
- 替换要求：公开部署前改为获得明确授权的素材或原创二创。

### archive-triptych.webp

- 用途：首页作品档案和项目总览的冰蓝、梅红、银灰三联画。
- 来源：为 WAHT 页面生成的视觉草案。
- 状态：尚未完成人工版权与公开使用审核。
- Git：已加入 `.gitignore`，审核通过前不提交。

## 使用规则

- 页面代码可以引用这些本地文件，但公开部署前必须执行素材审核。
- 不要把来源不明的网络图片移动到 `public-safe`。
- 替换图片时保持文件名稳定，可以避免修改组件代码。
