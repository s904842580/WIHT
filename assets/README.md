# 素材目录

素材目录用于管理胡桃主题、游戏参考、板绘、3D 和可公开素材。

## 当前规则

- 当前阶段可以收集网络和官方素材，仅供个人本地学习。
- 不要将官方素材用于公开部署或商用展示。
- 后续公开展示只使用 `public-safe/`。

## 目录

```text
assets/
  official-reference/   # [LOCAL] 官方素材参考
  fan-reference/        # [LOCAL] 网络同人参考
  generated/            # [NEXT] AI 生成素材
  original/             # [NEXT] 自己原创素材
  public-safe/          # [LATER] 可公开素材
  hutao-theme/          # [NOW] 胡桃主题规则
  drawings/             # [NEXT] 板绘作品
  models/               # [NEXT] 3D 作品
```
